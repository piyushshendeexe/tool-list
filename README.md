# Recon

Reconnaissance resources organized by methodology.

## Tool Lists

- [Recon Tool List](tool-lists/recon.md)

## Categories

- **Passive Recon** — Information gathered without directly interacting with the target.
- **Active Recon** — Information gathered through direct interaction with an authorized target.
- **Network Footprinting** — Network discovery, traffic analysis and scanning resources.

> **Authorization:** Only use active reconnaissance and scanning tools against systems and networks where you have explicit permission.
