# Recon Tool Lists

A categorized collection of reconnaissance tools and resources.

> Use these tools only on systems, domains, and networks you own or have explicit authorization to assess.

## Structure


## Passive Recon

| Tool / Resource | Purpose | Link |
|---|---|---|
| Wappalyzer | Identify technologies used by a website | https://www.wappalyzer.com/ |
| BuiltWith | Identify website technology stack | https://builtwith.com/ |
| WhatWeb | Web technology fingerprinting | https://github.com/urbanadventurer/WhatWeb |
| WebHTTrack | Website mirroring / offline copy | https://www.httrack.com/ |
| WHOIS | Domain registration and ownership-related information | https://lookup.icann.org/ |
| Netcraft | Website, hosting, infrastructure and technology research | https://www.netcraft.com/resources/research-tools |
| DNSRecon | DNS enumeration and reconnaissance | https://github.com/darkoperator/dnsrecon |
| DNSDumpster | DNS, hosts and subdomain-related discovery | https://dnsdumpster.com/ |
| WAFW00F | Web application firewall fingerprinting | https://github.com/EnableSecurity/wafw00f |
| Sublist3r | Subdomain enumeration using public sources | https://github.com/aboul3la/Sublist3r |
| Google Dorks | Search-engine-based discovery of publicly indexed information | https://www.google.com/ |
| GHDB | Collection of Google hacking queries/dorks | https://www.exploit-db.com/google-hacking-database |
| theHarvester | Collect emails, hosts, domains and related OSINT | https://github.com/laramies/theHarvester |
| Have I Been Pwned | Check whether an email appears in known data breaches | https://haveibeenpwned.com/ |

## Active Recon

| Tool | Purpose | Link |
|---|---|---|

## Network Footprinting

| Tool | Purpose | Link |
|---|---|---|
| Wireshark | Capture and analyze network traffic | https://www.wireshark.org/ |
| ARP-Scan | Discover hosts on local networks using ARP | https://github.com/royhills/arp-scan |
| Ping | ICMP connectivity and host discovery | https://man7.org/linux/man-pages/man8/ping.8.html |
| FPing | ICMP-based discovery of multiple hosts | https://fping.org/ |
| Nmap | Network, port, service and OS scanning | https://nmap.org/ |
| Zenmap | Graphical interface for Nmap | https://nmap.org/zenmap/ |
| Nmap Automator | Automate common Nmap scanning workflows | https://github.com/21y4d/nmapAutomator |
| Masscan | High-speed port scanning | https://github.com/robertdavidgraham/masscan |
| RustScan | Fast port discovery | https://github.com/RustScan/RustScan |
| AutoRecon | Automated reconnaissance and enumeration | https://github.com/Tib3rius/AutoRecon |
